# `disable-model-invocation: true` für die bestehenden Skills

Abgelehnt am: 2026-11-17
Grund: Unsere grundlegenden Skills sollen von selbst greifen. Mit dem Feld ließen sie sich nur noch über `/name` aufrufen.
Stattdessen: Das Feld nur für neue Skills nutzen, die ausschließlich Martin startet, zum Beispiel einen künftigen Skill `grilling`.
