# Abgelehnte Ideen

Hier liegt je abgelehnter Idee eine kurze Datei. So wird dieselbe Idee nicht in jeder Session neu vorgeschlagen.

Vor einer Änderung an einem Skill hier nachsehen. Passt ein Vorschlag zu einem Eintrag, nicht umsetzen, sondern Martin auf den Eintrag hinweisen. Ändert sich die Lage, kann die Entscheidung neu besprochen werden.

Aufbau einer Datei, Name in Kleinbuchstaben mit Bindestrichen:

```
# <Idee in einem Satz>

Abgelehnt am: JJJJ-MM-TT
Grund: <warum nicht>
Stattdessen: <was wir tun, falls es etwas gibt>
```
