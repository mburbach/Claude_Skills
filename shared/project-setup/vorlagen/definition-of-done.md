# Definition of Done

Eine Änderung ist fertig, wenn alle Punkte abgehakt sind.

- [ ] Tests zuerst geschrieben, rot gesehen und jetzt grün
- [ ] `{{CMD_CHECK}}` ist grün
- [ ] CI (Continuous Integration, automatische Prüfung im Repository) ist grün
- [ ] Review ist erledigt
- [ ] Doku angepasst: README, Architekturdoku in `docs/architektur.md` (arc42) und bei einer Architekturentscheidung eine ADR (Architecture Decision Record) in `docs/adr/`
- [ ] Keine Secrets (Passwörter, Tokens, Schlüssel) im Code, in Tests oder in Commits
- [ ] Commit nach dem Commit-Standard aus `CODING_STANDARDS.md`
